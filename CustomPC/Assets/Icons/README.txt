Individual SVG source URLs/original hashes and PNG hashes: sources.json

The 22 UI icons were converted to transparent 192x192 PNGs on 20 October 2026.
Only PNGs are embedded. IconAssets.cs loads and caches the images using
System.Drawing, scales them down and tints their alpha shapes for each control.
No SVG NuGet package, runtime download or conversion tool is required.
The password field uses eye.png when masked and eye-off.png when revealed.

triangle-alert.png: Warning icon by Icons8 (https://icons8.com/icons/set/warning), downloaded from https://img.icons8.com/ios/50/error--v1.png. Other icons retain their existing Lucide license.
