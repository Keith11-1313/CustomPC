Individual source URLs and SHA-256 hashes: sources.json

SVG files are the downloaded originals and the only icon image assets.
They are embedded application resources. IconAssets.cs loads them and
SVG.NET renders the vectors directly at the required size and UI colour.
The app does not contact an icon server or require a conversion tool.
The password field uses eye.svg when masked and eye-off.svg when revealed.
